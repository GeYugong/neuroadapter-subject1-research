# 独立语义探针 C：结果与边界

## 目的与执行范围

本实验检验既有脑输入是否包含可以独立读出的图片语义信息，而非继续训练或修复 NeuroAdapter。执行代码版本为 `de6bd4c`。原有 B0、H5000、L5000、R 权重全部保留；新增 NeuroAdapter 更新数和扩散生成图片数均为 0。未访问标准 test1000。

原 8500 训练图片按固定 namespace `semantic-probe-c-v1` 和图片 ID 的 SHA256 排序，划分为 7500 fit 与 1000 tune。独立 StandardScaler、PCA 和 Ridge 仅在 fit 范围内拟合；按 tune 前向识别率冻结唯一配置后，用全部 8500 图片重新拟合，再评价既有 500 内部验证图片。该验证集曾被用于之前的模型选择，因此本轮属于探索性诊断，不是独立测试。

输入使用已审查的有效顶点均值响应，保持 200 parcel 的有效顶点顺序并去除 padding。目标为固定 CLIP ViT-L/14 的单位归一化图像特征，GT 使用原终点评价的 raw imgBrick 预处理，而非旧诊断的 512 像素 GT。输入抽查逐元素一致，R/L 的验证 GT 特征与缓存逐元素一致；原终点 cosine 重评分误差小于 `1.6e-7`。

## 选参与对照

固定搜索 PCA 256/1024 维与 Ridge alpha 0.1/1/10/100/1000，共 10 个候选。PCA 使用 randomized、固定 seed、不 whiten；Ridge 带截距，目标为求和平方误差加 L2 惩罚。精确并列时优先低维，其次较大 alpha。

选中 **1024 维、alpha=0.1**，tune 前向识别率 **89.8692%**。该配置同时位于维数上边界、alpha 下边界，不能宣称找到全局最优；未根据验证结果扩展搜索。PCA 256/1024 在 7500 fit 上保留方差为 73.8621%/85.2495%，8500 refit 为 73.7288%/84.8843%。拟合阶段耗时 96.07 秒，使用 CPU；GPU 仅用于特征提取。

五个固定标签置换各自完成相同的 10 候选选参和 8500 refit，共 60 行候选记录。全部选参曲线见 [tuning_results.csv](../manifests/semantic-probe-c-v1/tuning_results.csv)。五次置换仅作为描述性对照，不报告精确置换 p 值。

## 统一 500 图评价

预测为行、GT 为列计算 float64 cosine。前向二选一将正确目标分别与其余 499 个目标比较，平局半分；Top1/5 使用同一 500 图候选池。R/L 每图两个候选分别评分后再图内平均，不先平均 embedding。该口径不同于旧版 GT 行、重建列的相关性识别率，不能直接与旧数值相减。

## 结论与后续定位范围

1. C 明显超过均值和五个打乱对照，支持当前脑输入中存在可独立读出的图片特异语义信息，不能将现有生成效果不足简单归因为输入完全无信号。
2. 统一检索口径下，C 超过 R/L 生成图可读出的语义信息。但 C 直接受 CLIP 特征监督，生成模型承担不同任务；这不是生成质量等价比较，更不是达到论文效果的百分比。
3. 后续定位范围应放在脑输入到生成输出之间的信息利用过程。结果不能单独判定 ParcelMapper 是根因，也不能证明空间位置、数量等细节能够被生成恢复。本轮不追加训练、不新增 CLIP loss、不替换 R，也不恢复结论性 ROI/IBBI 实验。
