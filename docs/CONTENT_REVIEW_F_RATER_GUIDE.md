# 160图内容评阅说明

仅将 reviewer_pack 文件夹交给评阅者。不要查看选择器映射、旧评分或其他人的标注。两位评阅者分别完成同一套图片；只有一人时如实记录，不称多人独立盲评。

打开 index.html，共16页，每页10个案例。F001至F160是匿名案例号，GT是目标，A/B/C是匿名输出。同一输出只显示一次，部分案例因此少于三张。各页面图片可在浏览器单独打开查看原始尺寸。

填写 ratings.csv，每个匿名输出一行；不要删除、追加或改动 case、output。可用电子表格打开，完成后导出UTF-8 CSV。最好每完成一页保存一次。不同评阅者使用独立副本，不交流标签。此版本使用CSV填写，不在网页中保存评分。

## 四个维度

| 列 | 判断内容 |
| --- | --- |
| object | 主要对象类别是否正确：牛不是大象，飞机不是滑板 |
| action_relation | 关键动作及对象关系：刷牙、切蛋糕、持冲浪板等，而非仅有相似背景 |
| scene | 场景是否对应：门廊、厨房、海滩等 |
| count_layout | 主要对象数量、相对位置与构图是否保持 |

各列只填写：`correct`（正确）、`partial`（部分对应但存在实质偏差）、`wrong`（错误或目标内容缺失）、`uncertain`（无法判断或该维度不适用）。不适用原因写入notes；不强迫猜测。锐利、鲜艳和照片感不是内容正确的依据。四维分开记录，不合成总分。

## 整体内容选择

best列填写最忠实于GT的输出标签，例如 `A`，并列填 `A;B`。全部明显不对填 `all_wrong`；无法判断填 `uncertain`。同一个case的所有行填写相同best值。只有一张输出时仍可填all_wrong或uncertain，不必因为只有一个就判好。notes可用中文记下错误主体、动作、数量等具体问题。

到160张结束，不看完后换样本。全部评阅者的原始文件交回后统一揭盲；请同时说明实际评阅者人数、是否人工独立完成、是否曾看到方法标签。不能将AI代填称为人工结果。
