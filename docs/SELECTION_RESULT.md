## 选择依据

初筛入围 39844、199219、212500、239063、265625 步。复评的语义综合均值由 AlexNet-5、Inception、CLIP 三项识别率取平均。

| 更新步数 | 语义综合均值 | PixCorr | SSIM | CLIP (%) | 入围 one-SE | 综合排名值（低为优） |
| ---: | ---: | ---: | ---: | ---: | :---: | ---: |
| 39844 | 79.5307 | 0.04154 | 0.30934 | 81.2661 | 否 | 不参与 |
| 199219 | 86.0498 | 0.07617 | 0.28446 | 86.2031 | 是 | 2.8667 |

212500 步的语义均值最高；239063 步落后 0.1351 个百分点，该配对差异的 bootstrap 标准误为 0.3174。按事先冻结的 one-SE 规则，四个后期权重进入候选集合，再按低层与高层指标组的平衡排名选择 239063。Bootstrap 为 10000 次，seed=20260901。该规则是模型选择准则，不是证明模型统计等价的检验。

因此，本次选择不是“最后一步最好”，也不是“CLIP 最高最好”。239063 的 CLIP 低于另外三个后期候选，但在合格集合中的三项低层指标均排名第一，综合排名最优。39844 的 SSIM 更高，但其语义表现未达到入围标准。

## 视觉检查

在固定验证顺序的 500 个位置中等距抽取 12 个位置，检查全部五个候选的 candidate-00，并另外展示选定权重的 candidate-01。抽样规则和 ID 保存在 `visual_sampling.json`，不根据生成效果选图，也不按 GT 筛选 seed。两张完整对照图已实际逐行查看。

- id 95、13938、32697：选定权重可以恢复部分浴室、洗手台、厨房语义，但物体位置、数量和构图并不忠实。
- id 7306、20317、44975：保留食物大类，但具体食材、餐具、色彩和摆放变化明显。
- id 27240：原图是摩托车下的一只猫，重建为包内两只猫；id 51517 保留鸟类语义，但原图的椅子和背景未恢复。
- id 38380：选定权重的 candidate-00 生成人形姿态的狗，candidate-01 则接近小孩进食，说明随机种子仍可能改变类别和具体内容。
- id 58522：披萨被生成为水面等不相关内容；id 72527：棒球场景偏成网球场景；id 65340：仅保留部分滨水环境，未恢复历史照片中的具体对象与布局。

结论：模型获得了部分可泛化的图像语义，但存在明显类别错误、空间错位和种子不稳定性。选定权重不代表这些问题已解决，不能宣称达到论文重建水平。不同数据划分和候选筛选协议下的论文指标只能作为背景参考。
