# generator-semantic-last-v1 最终报告

## 1. 实验边界

本轮以旧 `239063` 权重 R 为共同起点，R 的 SHA-256 为：

```text
bdca167505e0f1e62e025a5856299c56548dc40c2231740b8d2e1f84665b8217
```

控制组 K 使用固定学习率 `1e-5`、全新 AdamW 和原扩散损失微调 5000 个 local updates。实验组 M 使用相同初始化、数据顺序、主随机流和优化设置，在原损失之外加入训练期 CLIP ViT-L/14 残差语义损失；固定 `lambda_sem=0.00041042703470024083`，先运行 5000 个 local updates。

训练仍使用 Subject 1 的 8500/500 划分、2×RTX 4090、global batch 16、BF16 主路径、Min-SNR 5 和原 token dropout。未访问标准 test，未使用 C/E 选图，未改变脑输入归一化、模型结构或候选数量。

## 2. 启动前审计

- 16 张固定训练图的 `[200,626]` brain cache 与原始三次呈现 beta 重算逐元素一致。
- 公开作者 `process_training_batch()` 与当前 FP32 参考路径的 loss、梯度和一步 AdamW 更新处于预定浮点容差内，没有发现索引、token 顺序、梯度断路或错误 dtype 阻断。
- 8500 张训练图单独生成 CLIP 单位特征和训练均值，未包含 500 验证图或标准 test。
- 16 个固定 update 的梯度范数比一次性确定 lambda，未依据验证结果搜索。
- M 的 guidance generator、image projection 和 IP-K/V 梯度均有限且非零；VAE、文本编码器和 CLIP 无参数梯度。
- 10→20 update 恢复与连续 20 update 的模型 SHA 完全一致。

## 5. 固定 32 图检查

实际查看了固定 32 张图的 GT、B0、K5000 和 M5000 各两个 seed，共 224 张生成输出。该检查为单一 AI 的非盲定性检查，不冒充人工评分，也不按视觉结果重新选择 checkpoint。

主要观察如下：

- 飞机、浴室、办公桌、猫、网球、风筝、冲浪、公交、滑雪等粗类别通常能够保留，K/M 与 B0 整体接近。
- `5582` 的飞机、`15068` 的浴室、`26535` 的网球、`48376` 的冲浪、`50739` 的公交和 `57244` 的滑雪在三种权重中均较稳定，不能归因于新损失。
- `61868` 的斑马在 B0/K/M 中仍主要变成牛或象，K/M 没有恢复关键类别。
- `66875` 和 `72527` 的棒球场景仍常变为网球；`13223` 的单轨列车仍变为机场/飞机；`10361` 的长椅与儿童关系、`43065` 的剪刀、`52729` 的具体食物均未稳定恢复。
- `29018` 和 `55741` 的雪景属性仍被削弱；猫的数量、人物动作、道具和相对布局仍频繁错误。
- 未发现 K/M 特有的严重纹理崩坏、非有限图像或明显训练图复制证据，但也没有观察到 K 或 M 对主体、动作、场景和布局的一致改善。

## 6. 最终决定

本轮 `developed_candidate` 为 **K5000**，其推理权重 SHA-256 为：

```text
0fda9a9b615982297039b717d032e22ab465fdf4a8a53ed998c21885f86fecfd
```

实际训练实现提交为 `12305e0abc95d333aebf3e12c99c9279ab78fe37`，对应训练配置哈希为 `5722186546e36383f69014612c79e8b98398e6baacebb79cce6bb6a41d372828`。

K5000 的 S 相对 B0 提高 `0.6426` 个百分点，低于预定的 `1.0` 个百分点替换门槛；PixCorr、SSIM、EfficientNet 和 SwAV 也均低于 B0。因此：

```text
developed_candidate = K5000
recommended_generator = B0 / R239063
```

训练期语义辅助在这次固定资源试验中没有显示出超过短原损失控制组的额外收益。本轮按预注册边界结束：不延长 M、不更换 lambda、不改变 seed、不增加第三组训练，也不访问标准 test。
