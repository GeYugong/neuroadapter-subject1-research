# F-AI：两个子代理的匿名内容评阅

## 边界

根据新请求，由两个子代理分别查看同一固定160案例和406个匿名输出。两者不继承主任务历史、不查方法映射或旧评分、不读对方文件，各自保存完整四维标签、偏好和具体视觉备注。任务不是人工评阅，不能称两位真人或两个独立模型的盲评。两代理继承同一模型；分开上下文降低交流污染，不消除模型共同偏差。

沿用F全部样本、随机候选、去重、匿名排列和评分口径，不重新抽样、不生成图、不改变R/C/E。先冻结两份原始标签及哈希，再统一映射至方法。不同评分保留，不让主代理挑选、协调或覆盖。每名评阅者分开汇总，补充406个唯一输出的四维混淆表、一致率、未加权kappa及160案例最佳标签集合一致率。不将两代理乘160当320个独立样本，不据一致率验证生物学或人工有效性。

输出独立命名为content-review-f-ai-v1，程序report_content_review_ai.py不写原human_results。原人工验收仍未完成，AI结果仅补充内容审查证据。即使AI结果支持E，也最多支持待人工或独立数据验证的固定方案；不自动重训、调公式或恢复ROI结论。

三个输出都明显不对的87/160与84/160约为54.4%与52.5%。这仅涉及本轮E/C/固定随机选出的最多三张图，不代表全部八候选都错误，更不是所有可能采样都没有正确内容。

## 评阅一致性

406个唯一输出的四维完全一致率依次为89.41%、86.70%、83.99%、84.48%；未加权kappa为0.841、0.779、0.752、0.712。160案例的最佳标签集合完全一致率89.375%。同模型共享偏差可能造成一致，不能把这当成真人验证或独立复现实验。

## 本轮决定

双AI审查完成；人工验收未完成。E的既有识别指标收益保留，新增内容证据支持它相对随机具有部分场景收益，但相对C的整体忠实度增益仍未确认。没有充分理由宣布E失败或明显退步，也没有理由宣布重建修复、内容验收通过或与C等效。

将R+E保留为冻结的开发候选及对照，不提升为已验收正式方案。本次有限审查到此结束，不加样本、不继续调排序、不重训、不恢复ROI结论。若未来要改善大量缺失主体、动作和布局的问题，应另行批准生成端受控研究；本轮不执行该研究。
