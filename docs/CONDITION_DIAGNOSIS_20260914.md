# 固定权重的图像通路与脑条件诊断

日期：2026-09-14。状态：本轮四步诊断已完成。性质：探索性诊断，不是独立测试、重新选优或正式模型验收；连续历史保存在根目录 `EXPERIMENT_LOG.md`。

## 1. 研究问题与固定条件

目标是区分基础图像通路错误、脑条件通路失效、泛化不足及推理精度影响，判断是否存在无需重训的修复方向。没有执行训练、续训、旧权重比较或额外数据下载。

诊断对象为既有 selection 的 update 239063，实际使用 8500 张图训练，不能称为 9000 张图重训模型。模型 SHA256：

```text

```

从真实训练集合与既有 500 图验证集合中，各按 `SHA256(namespace:split:image_id)` 排序固定取 32 张。未读取生成效果进行挑选。各组内部循环错配完整 `[200,626]` fMRI，保留每个 parcel 的位置及专属映射关系。

每张图固定两个候选，候选批次大小为 2，DDPM 50 步，基线 guidance=4。保存并回放 VAE 初始 epsilon、初始扩散噪声和全部 50 次 DDPM 采样噪声，共 52 个实际噪声张量；不能用“相同 seed”替代跨精度的实际噪声相等。

## 2. VAE 往返

使用实际预处理，将图像缩放为 512×512、归一化至 [-1,1]，分别在新加载的 FP32 和当前 BF16 VAE 中执行 encode/decode。同时检查后验 mode 和固定噪声 posterior sample。FP32 禁用 autocast 和 TF32；BF16 使用当前 backend。

| 集合 | FP32 mode RGB MSE | BF16 mode RGB MSE |
| --- | ---: | ---: |
| 训练 32 张 | 0.002557 | 0.002541 |
| 验证 32 张 | 0.002338 | 0.002324 |

64 张图、两种精度、两种后验方式，共 256 次往返均未出现 NaN/Inf。8 页拼图已经逐行视觉检查，主要颜色、主体及空间结构保持一致，没有发现明显图像缩放、颜色变换或 VAE 解码异常。细节压缩仍然存在；往返正常不证明脑解码正确。

## 3. 配对去噪误差

每张图固定一次当前 VAE posterior latent 与一次噪声，在五个时间步分别使用正确/错配完整脑输入计算原始噪声预测 MSE。没有 CFG，也没有 token dropout；这里不是 min-SNR 加权后的训练总 loss。

表中 ΔL = 错配 MSE − 正确 MSE；正数表示正确脑输入降低误差。括号内为 ΔL>0 的图数。

| 时间步 | 训练 ΔL | 验证 ΔL |
| --- | ---: | ---: |
| 50 | 0.004497 (32/32) | -0.000239 (13/32) |
| 200 | 0.008467 (32/32) | 0.000351 (16/32) |
| 500 | 0.005908 (32/32) | 0.001574 (25/32) |
| 800 | 0.000852 (32/32) | 0.000293 (24/32) |
| 950 | 0.000250 (31/32) | 0.000239 (24/32) |

训练组各时间步均有较一致的优势；验证组低噪声 t=50/200 的优势不稳定，而 t=500/800/950 仍有正向平均优势。验证组后三个时间步的探索性 95% bootstrap 区间均在零以上，但没有进行多重比较校正，不作正式显著性声明。

因此不能将当前结果解释成“条件通路完全失效”或“验证图完全没有被利用”。更准确的描述是：对目标相关脑信息的利用能够泛化到部分高噪声阶段，但低噪声阶段的训练优势没有同样泛化。原始 MSE 的量级随时间步变化，不宜直接跨时间步比较 ΔL 的绝对大小。

## 4. 完整生成的条件对照

完整保留 256 张 BF16 重建图，按固定顺序检查全部 8 页拼图。下表先对每张图的两个候选平均，再对 32 张图统计。CLIP 是与目标图的 embedding cosine，不是识别准确率，更不是“达到论文水平的百分比”。PixCorr、SSIM 使用本轮预处理 GT，不用于替代正式八指标报告。

| 集合 | 正确 CLIP | 错配 CLIP | 平均优势 | 优势为正的图数 |
| --- | ---: | ---: | ---: | ---: |
| 训练 | 0.747590 | 0.519475 | 0.228116 | 31/32 |
| 验证 | 0.633064 | 0.546711 | 0.086353 | 23/32 |

目标 CLIP 平均优势的探索性 95% bootstrap 区间：训练 [0.188467, 0.267619]，验证 [0.045315, 0.128083]。正确减错配的 PixCorr 优势：训练 0.116621、验证 0.139671；SSIM 优势：训练 0.044242、验证 0.040493。低层指标没有表现出与 CLIP 完全相同的训练/验证差异，不能统称为“所有指标都泛化失败”。

条件改变后的像素 MAE 为训练 0.236819、验证 0.228399，说明图像确实改变；正确输入更接近目标的配对分数则进一步支持这种改变包含有用的目标信息。错配图对 donor GT 的平均 CLIP 相似度为训练 0.729697、验证 0.635263，与整条脑输入被替换的解释一致。

视觉上，训练图中的列车、飞机、行李、运动场景等经常保留目标大类，但布局、身份及数量仍有错误。验证组存在更明显的类别替换：例如 id=56963 的甜甜圈被生成海浪，id=16800 的滑板被生成为飞机，id=42302 的林中动物被生成为长颈鹿；这些失败均保留。验证组两候选平均 CLIP 优势不为正的 9 张图为：13223、15191、33256、41120、54054、56963、62587、65690、67261。该定义不是全部视觉失败的名单。

## 5. 推理路径对照

前序检查未发现基础数值或图像通路异常，因此通过 `stage4_gate.json` 进入 FP32 参考对照。使用同一个 checkpoint，从原始 FP32 源权重新加载模型，不将已舍入的 BF16 权重升精度冒充 FP32 参考；运算使用 FP32，禁用 TF32。样本、错配、候选批次、全部噪声、scheduler 和 guidance 保持不变。

精度审计补充：原方案中“关闭 autocast”的表述不够准确。当前 PyTorch 2.11 的原生成函数保留 `autocast(dtype=float32)` 上下文，开关为开启，但目标类型为 FP32，并不是低精度 autocast。新增 `check_fp32_reference.py` 使用两组冻结首图、共四个候选张量，对比显式关闭 autocast 的路径；两者逐元素完全一致，也与已保存 PNG 一致。UNet、文本编码器、VAE encoder/decoder、脑映射和图像投影六类模块输出均实测为 FP32。核验范围是这两张固定图，不声称另外重跑了全部 64 张；证据为 `fp32_reference_audit.json`。VAE 单独往返阶段的 FP32 则确实使用关闭的 autocast。

FP32 完成全部 256 张重建并逐行检查 8 页拼图。下表为同图同候选的 FP32 减 BF16 平均指标变化；均采用正确脑输入。

| 集合 | CLIP cosine 变化 | PixCorr 变化 | SSIM 变化 |
| --- | ---: | ---: | ---: |
| 训练 | +0.002525 | +0.001111 | +0.000543 |
| 验证 | +0.000670 | +0.001762 | +0.001215 |

六项变化的探索性 95% 区间都跨过零。验证 CLIP 变化区间为 [-0.005286, 0.006430]，并非可确认的提升。主要语义与布局错误在 FP32 下继续出现，未见仅升精度即可修复的证据；这也不是对 BF16 与 FP32 做出的严格等效性证明。

随后在当前 BF16 路径上测试预设 guidance=2/6，与既有 guidance=4 对比；只使用正确脑输入，图像、两个候选、全部噪声、batch 和 scheduler 不变。不同时改变 precision，不逐图选最优 guidance。

| 集合与设置（相对 g4） | CLIP cosine 变化 | PixCorr 变化 | SSIM 变化 |
| --- | ---: | ---: | ---: |
| 训练 g2 | -0.039152 | -0.009640 | +0.031159 |
| 训练 g6 | +0.006991 | -0.005973 | -0.033173 |
| 验证 g2 | -0.002843 | -0.023083 | +0.030338 |
| 验证 g6 | -0.007924 | -0.013763 | -0.034731 |

验证 g2 的 PixCorr 变化区间为 [-0.041975, -0.006526]，SSIM 变化区间为 [0.021259, 0.039393]；验证 g6 的 SSIM 变化区间为 [-0.042448, -0.027434]。均为未校正的探索性区间。两个设置的验证 CLIP 平均值都没有改善，其变化区间跨零。

全部 8 页 guidance 拼图已检查。g2 经常更平滑、对比度较低，g6 经常更锐利、饱和度更高，但这种观感变化没有系统纠正语义类别错误。例如 id=56963 在三个 guidance 下仍生成海浪，id=16800 仍生成飞机形态。不能将更高的 SSIM 或更鲜艳的图等同于更准确的脑解码。

## 6. 本轮结论

1. 当前图像预处理与 VAE 往返未发现明显异常，BF16 数值精度不是已观察到的主要故障来源。
2. 模型确实利用与目标有关的 fMRI 信息，不能将当前问题归结为脑条件完全无效。
3. 训练组的语义优势强于验证组，验证低噪声去噪优势较弱，支持进一步定位泛化与细节重建问题；小样本结果不能唯一归因于过拟合，也未排除数据质量或其他环节差异。
4. 本轮未找到仅切换 FP32 或将 guidance 改为 2/6 就能明显修复重建质量的证据。guidance=2 存在 SSIM 与 PixCorr 的取舍，不作为整体修复方案。
5. 保留原权重及默认推理配置，不继续参数搜索或启动重训；该权重仍是诊断对象，尚未验收为正式研究模型。下一研究决策应针对泛化差异与训练/验证数据和目标的核查，而不是直接追加 500 epochs。

## 7. 审计与限制

首轮噪声回放错误地将初始扩散噪声设为 BF16，而原路径该调用实际是 FP32。两组首图均被逐元素一致性断言拦截，失败运行保留于 `bf16-failed-noise-v1`。只修正诊断脚本 dtype 后，两组首图均与未修改的原生成函数完全相等（最大差 0），随后正式对照才继续。没有把失败尝试混入统计。

每个集合只有 32 张图、每图两个候选和一个固定 donor；所有区间以图像为重采样单位，不把 64 个 image-seed pair 当作 64 个独立样本。这些区间属于固定抽样、固定错配下的探索性描述，未做多重比较调整。验证集已经参与选优，不能作为新独立测试，也不能按每张 GT 选择最优 precision/guidance。

正式保留 768 张完整生成 PNG、256 张 VAE 往返图、64 张预处理 GT、64 份实际噪声银行、320 对去噪误差、768 行逐候选分数及 256 行正确/错配配对分数。32 页拼图覆盖全部正式输出，无成功样本筛选；另外的少量一致性核验输出不计入正式样本量。

全量 PNG、噪声张量、逐图分数、失败尝试及控制台记录保存在服务器项目根下 `runs/diagnostics/20260914-condition-path`。小型统计与图像/噪声哈希索引在 `manifests/diagnosis-20260914`；含图报告在本地 `artifacts/diagnosis-20260914/REPORT.md`。刺激图与重建图片不进入 public Git。主日志保存命令、commit、用时和所有处理过程。FP32 与 BF16 之外的精度、其他 scheduler、更多噪声重复和独立测试集均未在本轮测试。
