# 配对学习率实验：终点评价摘要

## 当前完成范围

两条微调各完成5000次更新，训练配对审计通过；小样本各保存节点的生成、终点错配生成、完整500张内部验证图的终点评分均已结束。现已用已有PNG完成32张训练图与32张验证图的轨迹评分，并逐页视觉检查完整32页图册，没有重新生成图片或训练。本报告完成该学习率分支的阶段收尾，进入独立语义探针C。

## 实验设计与来源

实际运行代码提交：`7cd3d250d0471e2d12dce8e2df2a105bdfba7355`。H/L均从原159375 snapshot开始，全新AdamW；原239063作为只评价参考，未替换或覆盖。

- 原500张内部验证图，2候选、候选batch2、50去噪步、guidance4、相同实际采样噪声；不使用标准test、不按GT选候选。
- H耗时3095.57秒，L耗时3083.09秒；两组保存0/1000/2500/5000，终点完整恢复状态保留在服务器。

## 阶段结论与限制

低学习率相对于未微调起点和同预算高学习率组均有小幅正向变化，两个预定主区间均高于零。但L−B0未达到预先规定的0.01实际改善阈值，未满足进入独立训练随机序列复验的联合条件。**不能把未达到实际收益阈值解释成完全没有收益。**相对于原239063的优势仍不明确，区间跨零。

辅助结果并非全面提升：L相对B0的SSIM下降，相对R的PixCorr下降。因此不宣称整体修复，不用单个语义指标替换原权重。样本来自已用于选优的内部验证集，仅一个配对训练seed，结论仍是探索性的。

预定规则下一研究方向为独立语义探针C。保留L5000为开发候选，不替换R，不继续扫学习率或延长微调，不恢复正式ROI/IBBI结论性实验。

小样本L终点验证分数低于B0，与完整500图的正向均值不同。该差异不推翻预定完整500图主分析，反而说明不能靠固定32图诊断集决定是否微调有效。L2500训练分数较高不构成更换终点的理由。

正确减错配CLIP均值：训练B0/H/L/R分别0.174872/0.145389/0.181037/0.228116；验证分别0.102440/0.094529/0.088803/0.086353。所有终点平均仍为正，但L没有在这32张验证图中显示更强的正确输入优势。未为这些描述性小样本比较追加显著性结论。

## 完整视觉审查

全部64图、2候选、8节点正确输入轨迹，以及4终点正确/错配对照均按原顺序呈现。16页轨迹图与16页终点对照图全部逐页检查；没有只保留表现好的样本。图册使用已有PNG，重排展示不代表重新生成。以下例子仅用于描述已经检查过的全体图册，不是视觉定量统计。

- 训练21652：H5000两候选明显偏离电脑主题，L保留较多电脑结构，但候选1仍混入马桶；R两候选较接近电脑场景。
- 训练33748、50780：机车、客机主题大体保持，视角、文字及结构随节点变化。训练16584的镜面人像却在全部节点持续变成公交场景，微调没有消除此类语义错误。
- 验证56963：甜甜圈在两候选、各节点中持续变成海浪或海岸；验证16800的滑板细节仍常被飞机形状替代。不存在整体性修复证据。
- 验证71264的电脑工作台主题相对稳定；验证58157候选1在后期出现人与宠物共同入镜，相比早期仅宠物更接近GT。这类局部改善与失败同时存在。
- 验证51865门廊持续生成厨房；验证29511火车在候选0接近空天际线、候选1偏成建筑局部，L未普遍改善对象及布局。
- 错配完整脑输入会改变生成主题，例如训练33748机车换入行李donor后转为行李场景，验证71264电脑换入食物donor后转为餐食。该观察支持条件敏感性，但不能单独证明准确重建，也不能掩盖正确输入本身的错误。

总体上L相对H的改动通常较小，但“更接近B0”不等于“更接近GT”。原R在部分训练样本上仍较好，完整验证辅助指标也存在取舍。因此仅保留小幅内部验证语义增益结论，不提升L为正式模型。

含全部32页图的本地报告位于 `artifacts/paired-lr-probe-v1/REPORT.md`，配套原始图册在其 `trajectory/galleries/` 下。public Git保存文字报告、逐图分数和图册SHA清单，不上传图片。
